1. OTP Authentication (/api/otp)
Send OTP

Method: POST
URL: http://localhost:5000/api/otp/sendOtp
Body:
json
{
  "mobileNumber": "9876543210"
}
Verify OTP (Creates user if new)

Method: POST
URL: http://localhost:5000/api/otp/verifyOtp
Body:
json
{
  "mobileNumber": "9876543210",
  "otp": "123456"
}
👤 2. User Profile (/api/users)
Update Profile

Method: PUT
URL: http://localhost:5000/api/users/updateProfile
Body:
json
{
  "userId": "65b2a2b7f3a8c90012345678",
  "name": "Jagathratchagan",
  "email": "jagath@example.com"
}
❤️ 3. Wishlist (/api/wishlist)
Add / Remove from Wishlist (Toggles state)

Method: POST
URL: http://localhost:5000/api/wishlist/updateWishlist
Body:
json
{
  "userId": "65b2a2b7f3a8c90012345678",
  "serviceId": "6abb8542c534e0def1143114"
}
Get User's Wishlist

Method: GET
URL: http://localhost:5000/api/wishlist/:userId
(No body required. Replace :userId with actual user ID, e.g. http://localhost:5000/api/wishlist/65b2a2b7f3a8c90012345678)
🛒 4. Orders & Checkout (/api/orders)
Preview Order / Calculate Price

Method: POST
URL: http://localhost:5000/api/orders/preview
Body (For Pooja):
json
{
  "poojaId": "6abb8542c534e0def1143114", 
  "whatsappNumber": "9876543210",
  "participants": [
    { "name": "Jagathratchagan" },
    { "name": "Participant Two" }

  "gotra": "Kashyapa",
  "doesNotKnowGotra": false,

  "bookingDate": "2026-10-06T00:00:00.000Z"

🙏 5. Pooja Details (/api/pooja-details)
Get Pooja Details by ID

Method: GET
URL: http://localhost:5000/api/pooja-details/:poojaId
(No body required. Replace :poojaId with actual pooja ID)
